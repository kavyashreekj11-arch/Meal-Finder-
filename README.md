# Meal Finder

A responsive recipe discovery web application built with **HTML, CSS, and JavaScript**, using the **TheMealDB API** to dynamically load meal categories, recipes, ingredients, measurements, and cooking instructions.

## Project Links

- **Project / Code:** https://github.com/kavyashreekj11-arch/Meal-Finder-
- **GitHub Repository:** https://github.com/kavyashreekj11-arch/Meal-Finder-
- **Live Project:** Not deployed

## Features

- Search for meals using the TheMealDB API
- Search using the search button or **Enter** key
- Browse recipe categories
- Filter meals by category
- Display dynamic meal cards
- Open detailed meal information
- Display ingredients with numbered indicators
- Display ingredient measurements
- Display cooking instructions
- Category navigation through the side menu
- Browser **Back / Forward** navigation
- Responsive layout for different screen sizes

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/kavyashreekj11-arch/Meal-Finder-.git
```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` using a local development server such as **Live Server**.

4. Use the search bar, categories, meal cards, and navigation to explore the application.
